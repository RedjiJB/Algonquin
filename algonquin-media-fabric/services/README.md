# Services

- `media-api/` — public product API
- `asset-registry/` — asset identity, versions, provenance, and state
- `job-orchestrator/` — pipeline planning, dispatch, retry, and cancellation
- `metadata/` — searchable technical, semantic, and rights metadata
- `delivery/` — authenticated renditions and distribution
- `moderation/` — content and policy review
- `spatial/` — scenes, poses, coordinates, captures, and spatial relationships
