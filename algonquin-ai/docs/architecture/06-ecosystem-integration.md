# Ecosystem Integration

- AC Cloud provides shared identity, events, edge, observability, and platform
  services.
- ACF becomes a routable compute backend only at the documented Phase 9 merge
  point.
- AC Media Fabric owns generated and transformed media assets, provenance, and
  delivery.
- AC Fediverse owns ActivityPub publication, remote federation, and social-product
  moderation.
- Shared spatial contracts allow AI responses, campus knowledge, media scenes, and
  federated objects to refer to places without sharing precise private location by
  default.

AC AI integrates through authenticated APIs and versioned events. It must not
couple model routing or agents to another repository's implementation details.
