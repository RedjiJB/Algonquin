# Services

- `activitypub-gateway/` — the only public ActivityPub boundary
- `actors/` — local actor identity and profiles
- `inbox/` and `outbox/` — durable activity processing
- `federation/` — delivery, retries, discovery, policy, and peer state
- `moderation/` — reports, review, decisions, and appeals
- `media-proxy/` — safe remote-media retrieval and caching
- `search/` — authorized local discovery
- `notifications/` — deterministic notification delivery
- `spatial/` — privacy-aware place and spatial context
